# Копилка воды — (AWS Lambda, Python)

Голосовой навык , который считает выпитые стаканы воды за день.
Это учебно-боевой шаблон: минимум кода, корректные финалы сессии, обработка ошибок.

## Что умеет

| Команда | Ответ навыка |
|---|---|
| «выпил три стакана» | записывает 3 стакана и называет текущий итог |
| «сколько я выпил» | называет итог и сколько осталось до цели (8 стаканов) |
| «обнули счётчик» | сбрасывает дневной счёт |
